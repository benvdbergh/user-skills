# Skill Escalation Boundaries

## Owns

- Format-agnostic semantic diagram model (nodes, edges, clusters, diagram kind).
- Author / Revise / Verify / Interpret for draw.io, HTML/SVG, Mermaid, and Obsidian `.canvas` (JSON Canvas 1.0).
- Editorial design system for HTML/SVG output.
- Diagram-type layout conventions (`references/type-*.md`) and complexity budget.
- Obsidian Canvas layout and JSON schema when emitting `.canvas` files.

## Does Not Own

- Vault ontology, entity IDs, or KuzuDB writes (enterprise model store).
- ArchiMate / EA repository modeling and arc42 document sets.
- Creating or restructuring vault Markdown note bodies beyond card placement paths.
- draw.io desktop vs diagrams.net product issues; Obsidian plugin bugs.
- Branded KION or corporate template selection (kion-design, kion-pptx).

## Escalate To

- **`enterprise-architecture`** — ArchiMate views, capability maps tied to EA metamodel.
- **`enterprise-model-store`** — canonical entity paths, approved note locations in Ai-Vault.
- **`tech-documentation`** — full doc sets, governance, Word/PDF export pipelines.
- **`product-knowledge-catalog`** — product/capability/feature naming for diagram labels and note links.
- **Vault `documentation` skill (Ai-Vault)** — CAI note templates and vault folder conventions for new `file` targets.

## Escalation Triggers

- User needs many new vault notes with frontmatter/ontology, not just canvas JSON.
- Diagram content must align to KuzuDB or approved enterprise entities.
- Request is only “convert PDF to diagram” or Office artifact export.
- User wants interactive HTML dashboard beyond static SVG diagram.
