# Skill Escalation Boundaries

## Owns

- Spec-first artifact orchestration: `spec`, `PRD`, `Plan`, `CONSTITUTION`.
- Requirement quality standards, measurable outcomes, and quality-gate framing.
- Scale-aware rigor selection (startup/growth/enterprise) for specification artifacts.
- Handoff contract quality to planning and architecture skills.

## Does Not Own

- Detailed solution architecture design and topology trade-off resolution.
- UX interaction/system design details.
- Enterprise portfolio modeling or ontology modeling.
- Backlog decomposition into epics/stories/tasks.
- DOCX/PDF/PPTX export automation and broader documentation portfolio governance.

## Escalate To

- **`software-architecture`** when architecture decisions are complex, high-risk, or unresolved.
- **`project-planning`** when converting approved specs/PRDs/plans into epics/stories and dependency graphs.
- **`ux-designer`** when UX flows, information architecture, or design-system decisions are needed.
- **`enterprise-architecture`** when the request is enterprise-model, ArchiMate, or portfolio-level.
- **`tech-documentation`** for broad documentation workflows, audits, and Office artifact routing.

## Escalation Triggers

- More than three unresolved architecture decisions block Build Ready gate.
- Requirement set spans multiple bounded contexts with unclear ownership.
- Compliance/governance demands exceed project-level constitution framing.
- User asks for implementation backlog structure rather than specification artifacts.
