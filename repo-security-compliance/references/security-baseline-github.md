# GitHub Security Baseline

- SECURITY.md exists with reporting instructions and supported versions.
- Private vulnerability reporting is enabled.
- Security advisories process is used for private triage and disclosure.
- Dependabot alerts and security updates are enabled.
- Code scanning is enabled.
- Secret scanning and push protection are enabled where available.
- Branch rules enforce reviews, status checks, and anti-force-push controls.
