# Security Policy and Disclosure

Recommended policy elements:
- supported versions
- private reporting channel
- acknowledgement and triage timeline
- coordinated disclosure expectations

Disclosure flow:
1. private report intake
2. triage and validation
3. draft advisory
4. private fix development
5. advisory publication
