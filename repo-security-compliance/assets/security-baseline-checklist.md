# Security Baseline Checklist

- [ ] SECURITY.md present
- [ ] private vulnerability reporting enabled
- [ ] advisories process documented
- [ ] Dependabot alerts and updates enabled
- [ ] code scanning enabled
- [ ] secret scanning and push protection enabled where available
- [ ] branch protections enforce review and checks
- [ ] scorecard baseline captured

Sources:
- https://raw.githubusercontent.com/ossf/scorecard/main/docs/checks.md
- https://docs.github.com/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/available-rules-for-rulesets
