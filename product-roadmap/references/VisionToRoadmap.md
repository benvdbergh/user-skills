# Workflow: VisionToRoadmap

## Trigger

"Create a high-level roadmap from product vision."

## Steps

1. Capture vision anchors:
   - target users/segments
   - strategic outcomes and success metrics
   - constraints and non-negotiables
2. Select horizon model by scale (`framework-selection-by-scale.md`).
3. Define outcome themes per horizon (not feature lists first).
4. Map candidate features/enablers that could achieve each outcome.
5. Mark each item as:
   - committed
   - forecast
   - option
6. Validate coherence:
   - Does each feature tie to an outcome?
   - Are runway dependencies visible?
7. Produce roadmap artifact using `assets/high-level-roadmap-template.md`.

## Done Criteria

- Every horizon has measurable outcomes.
- Features are subordinate to outcomes.
- Runway/enabler line is visible.
