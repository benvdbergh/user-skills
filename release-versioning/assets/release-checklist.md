# Release Checklist

Use this checklist for each planned release.

## Pre-Release

- [ ] Commits since last tag follow commit convention.
- [ ] Version bump decision is documented (`MAJOR`/`MINOR`/`PATCH`/none).
- [ ] Breaking changes include migration guidance.
- [ ] Changelog entries are complete and user-focused.
- [ ] Test suite and required quality gates are green.
- [ ] Security and dependency checks pass.

## Tag and Notes

- [ ] Tag format is correct (`vX.Y.Z`).
- [ ] Release title and notes follow the template.
- [ ] Generated notes were reviewed and cleaned.
- [ ] Contributors and PR links are accurate.
- [ ] Pre-release flag is set correctly when needed.

## Publish and Verify

- [ ] Artifacts are published to all required registries/channels.
- [ ] GitHub release is published.
- [ ] Post-release smoke verification completed.
- [ ] Rollback/hotfix owner confirmed.

## Closeout

- [ ] Stakeholder notification sent.
- [ ] Follow-up issues captured from known limitations.
- [ ] Next iteration milestone updated.
