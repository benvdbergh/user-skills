## 3. Stage Definitions

### Stage 0: Newcomer
- Typical actions: issue feedback, docs clarifications, small fixes.
- Maintainer support: setup help, contribution orientation, friendly first review.

### Stage 1: Active Contributor
- Typical actions: repeated pull requests, issue triage, review comments.
- Growth signal: reliable delivery, constructive communication, standards adherence.

### Stage 2: Trusted Reviewer
- Typical actions: peer reviews, component ownership support, release assistance.
- Growth signal: consistent judgment and collaborative behavior.

### Stage 3: Maintainer Candidate
- Typical actions: roadmap input, moderation support, process stewardship.
- Promotion requirements: documented in governance files.
