# Prior art — market landscape for value proposition work

**When to load:** Calibrating terminology, extending the skill, or answering “what frameworks exist?”

This is a **curated map**, not an exhaustive literature review. Prefer authoritative publisher pages when citing externally.

## Widely used frameworks (commercial strategy / product)

| Framework | Typical use | Primary references |
|-----------|-------------|-------------------|
| **Value Proposition Canvas** | Fit between customer profile and offer; pains/gains | Strategyzer / *Value Proposition Design* |
| **Business Model Canvas** | Business model context (VP is one block) | Strategyzer |
| **Jobs to Be Done** | Progress, circumstances, hiring solutions | Multiple schools; start with reputable summaries + practitioner books |
| **Bain Elements of Value** | Taxonomy of value types; pyramid | Bain & Company publications |
| **Economic / EVC-style value cases** | Procurement, ROI narrative structure | Consulting and pricing literature (verify sources per engagement) |
| **Moore positioning statement** | Short category + contrast sentence | *Crossing the Chasm* |
| **HBR business-markets value props** | Proof, resonating focus, anti-puffery | HBR articles (e.g., Anderson & Narus stream) |
| **Lean value hypothesis** | Testability, experiments, learning loops | *The Lean Startup* |

## Adjacent concepts (not the same as “value proposition”)

- **Unique Selling Proposition (USP)** — classic advertising uniqueness claims (Rosser Reeves era); overlaps VP but often narrower and more promotional
- **Positioning (Ries & Trout)** — mental slot vs competitors; informs VP but is not the full canvas
- **Brand promise** — emotional/identity contract; can sit above functional VP layers
