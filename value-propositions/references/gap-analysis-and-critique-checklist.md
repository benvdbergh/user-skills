# Gap analysis and critique checklist — existing value propositions

**When to load:** Reviewing a document, slide deck, or messaging library for quality, completeness, and credibility.

## A. Setup (must be explicit)

- [ ] Segment and audience are identifiable from the text (if not: flag “unsegmented”)
- [ ] Customer job / outcome is stated (not only product attributes)
- [ ] Next-best alternative is inferable (if not: flag as “value undefined”)

## B. Traceability

- [ ] Each major claim maps to a **mechanism** (how it works), not only an adjective
- [ ] Features tie to **customer outcomes** (so what?)
- [ ] Differentiation is expressed relative to **something** (competitor, status quo, manual process)

## C. Value type balance

Using `bain-elements-of-value.md` as a lens:

- [ ] Table stakes are not oversold as unique
- [ ] At least one credible differentiated theme is present (where differentiation is the goal)
- [ ] Risk reduction / ease-of-doing-business is addressed for B2B if relevant

## D. Proof and credibility (`hbr-business-markets-value-propositions.md`)

- [ ] Evidence is named (even as “pilot planned”) vs pure assertion
- [ ] Absolute claims are justified or softened
- [ ] Metrics are not invented

## E. Failure modes

- [ ] Contradictions across sections (portfolio story vs single-product claims)
- [ ] “Everything to everyone” wording
- [ ] Hidden scope creep (implies whole product without dependencies listed)

## Output format suggestion

1. **Top 5 issues** (severity-ranked)
2. **Missing inputs** (from `organizational-inputs-and-assumptions.md`)
3. **Rewrite strategy** (segment split, proof plan, alternative clarification)
4. **Optional**: hypothesis tests (`lean-startup-value-hypothesis.md`)
