## Core idea

Customers evaluate offers across multiple **types of value**, not only functional performance. The framework clusters value into levels (conceptually pyramid-shaped): more objective/base needs near the bottom; more subjective/higher-order elements higher up (Bain draws on Maslow-like intuition).

**B2B-oriented categories** (names may vary slightly by Bain publication) commonly include clusters such as:

- **Table stakes** — minimum expected to be considered
- **Functional value** — economic performance, scalability, cost reduction, etc.
- **Ease of doing business** — reduced friction in buying, deploying, supporting
- **Individual** — personal career, reputation, reduced anxiety
- **Inspirational** — vision, purpose, market leadership narratives (use carefully; requires proof)

## Agent practices

- Tag each value statement with an **element type** (functional vs ease vs individual, etc.).
- Ensure the bundle covers **table stakes** before claiming differentiation.
- If messaging is entirely functional, ask what **ease / risk / personal** value exists for buyers—often decisive in B2B.

## No-gos

- Claiming Bain scores, NPS lift multiples, or statistics **without a cited source** from the user’s materials
- Treating the pyramid as a **scorecard** without customer evidence
