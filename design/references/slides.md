# Slides

Presentation and pitch-deck work is owned by the **`slides`** skill.

## Routing

1. Activate the `slides` skill (do not run slide creation workflows from `design`).
2. Pass user context (topic, slide count, audience, brand constraints).
3. For CIP-only HTML exports from mockups, use `scripts/cip/render-html.py` in this skill.

## Legacy references

Historical slide docs remain under `references/slides-*.md` in this folder for migration. The canonical skill is `slides` with `references/create.md`, `references/layout-patterns.md`, and related files.
